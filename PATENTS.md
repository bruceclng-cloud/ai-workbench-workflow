## Public-disclosure warning

This repository has been publicly available. Public disclosure can affect patentability and filing deadlines, and the rules differ substantially by jurisdiction. Some jurisdictions provide limited inventor grace periods; others generally require novelty before public disclosure subject to narrow exceptions.

Accordingly, any potentially patentable **future** workflow-engine mechanisms, execution algorithms, coordination techniques, security mechanisms, or other implementation details should be kept private until patent counsel has assessed them and any desired filing has been made.

## Recommended patent workflow

Before publishing a materially novel future mechanism:

1. record the invention privately with dated diagrams, implementation notes, inventors, problem statement, alternatives and known prior art;
2. conduct a prior-art review, including BMAD, GitHub Spec Kit, OpenSpec, LangGraph, CrewAI, OpenAI agent tooling, Microsoft Agent Framework and relevant academic/patent literature;
3. have qualified patent counsel assess novelty, non-obviousness, subject-matter eligibility, inventorship and jurisdictions;
4. if protection is justified, file before making the new mechanism public whenever possible;
5. only then publish the protected implementation and update this notice with accurate application information if appropriate.

## Current repository

The repository documents its influences openly. Those influences are important prior art and must not be misrepresented as original inventions. Any patent strategy should focus only on genuinely novel implementation details that are not already disclosed by those systems or other prior art.
